Eric-crashcar-mdc: OzSTAR quick start

Download the branch:

git clone --branch Eric-crashcar-mdc --single-branch git@git.ligo.org:lscsoft/spiir.git spiir-eric-crashcar-mdc
cd spiir-eric-crashcar-mdc/gstlal-spiir/share/scripts/OzStar

Use a separate copy of gstlal-spiir/share/scripts/OzStar as the working
directory for each run, and run all commands from that directory.

First edit the normal SPIIR inputs in pipeline.sh, including the GPS interval,
frame cache, detector-response map, PSD, bank directory, and injection XML when
running an MDC injection.

Set singlefar_dof in pipeline.sh to your effective degrees of freedom for this
run, or set SINGLEFAR_DOF in submit.sh. The required --singlefar-dof option
passes that value unchanged to all single-detector LLR calculations, including
their signal and noise terms. It stays fixed throughout the run and does not
depend on bank ID or source class. Template quantities use their existing path.
When reading another run's single background, use the same effective DOF that
was used to calculate that background's LLR values.

For the current test, submit.sh uses two workers and the single-detector
background accumulation window is one day; adjust both values for production.

Background input and output

To read and write this run's background, set:

noninj_stats_loc=`pwd`
inj_stats_loc=`pwd`

Keep both command lines enabled:

CMD="${CMD} --single-background-read-dir ${noninj_stats_loc}/${jobno}"
CMD="${CMD} --single-background-write-dir ${inj_stats_loc}/${jobno}"

To use another run's background, change noninj_stats_loc to that run's
absolute output root. Keep inj_stats_loc at this run's own working directory.
pipeline.sh appends the matching worker directory (000, 001, and so on).

Every run follows the same pipeline and accumulates its own background.
FAR uses the configured input directory and refreshes independently of local
background publication. For MDC, use a continuing no-injection run as that
input source and keep this run's output directory separate. Select the correct
worker/bank configuration and wait for complete input backgrounds before launch.

The two single-background options default to the worker output directory when
omitted; specifying only a read directory still writes locally. Configure the
standard normal-SPIIR inputs, including injection XML where needed, then submit:

sbatch submit.sh

The zerolag outputs are written under each worker directory, for example:

000/000_zerolag*.xml.gz
001/001_zerolag*.xml.gz
